# AI Architecture

## Boundary & Safety
The AI is strictly a personalization layer. It does **not** query the database or invent communities.

1. **Grounded Context**: The AI only receives the top deterministic candidates generated by the recommendation engine.
2. **Structured Output**: The AI must respond with a `NavigatorResponse` (validated by Zod), detailing next steps and related community IDs.
3. **Validation**: We verify that the AI hasn't hallucinated IDs. If an unrecognized ID is returned, the step is rejected or stripped of the ID.
4. **Fallback**: If the AI request times out or fails, the application falls back gracefully to present the deterministic recommendations directly.
